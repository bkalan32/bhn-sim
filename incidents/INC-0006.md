## What changed, when, can we undo it
The three questions on every bridge, all answered by the pipeline without a human:

1. **What** — `rollout history` revision _N_: "build _N_: add velocity check for fraud team"
2. **When** — the vertical annotation on every dashboard
3. **Undo** — `rollout undo`, executed by the `post { failure }` block; revision _N+1_ says "AUTO-ROLLBACK"

## Why the tests were green
The unit test activates a **$25** card. The velocity check blocks **≥ $50**. Production
traffic is 25/50/100 in equal share, so two-thirds failed. Tests green, deploy green,
pods healthy, `/healthz` fine — the rollout *completed*. Only traffic told the truth.

This is the most common shape of a real bad release.
